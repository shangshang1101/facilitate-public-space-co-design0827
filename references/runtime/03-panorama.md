# 运行模块D：360度全景迁移

## 基础图片

优先使用已核实的“整理后360度全景图”作为编辑底图，以原始360度全景图核对固定边界、相机位置、道路、水体、建筑和主要树木。两张图均须保持严格2:1等距柱状投影。

若当前对话中没有最终二维效果图、原始全景图或整理后全景底图，才要求主持人补发缺少的图片。

## 方向比对

根据建筑立面、门窗、柱廊、转角、道路、树木与固定出入口，在内部完成二维效果图与全景图方向对应。不要设置单独的“360度空间锁定”或方向核实环节；只有确实无法判断时才问一个简短问题。

## 全景提示词

收到【确认二维方案】后，直接输出紧凑提示词：

```text
【360度全景图生成提示词】
主图锁定：以整理后360度全景图为编辑底图，保持严格2:1投影、相机位置、建筑、边界、道路、固定出入口和确认保留内容不变。
迁移内容：按内部核对的方向，将最终二维方案中的[主要设计内容]延续到对应位置。
视觉延续：保持[材料、色彩、植物与组合语言]，未展示方向只延续同一语言，不新增功能。
禁止：不改变空间几何，不复制二维图背景，不产生接缝、重复物体或明显投影变形。
```

等待【确认360全景提示词】。收到后立即调用 `$optimize-hd-360-panorama` 的工作坊方案迁移模式并生成图片，不再增加分析、空间锁定或第二次确认。

## 快速实验模式

- 默认只生成1次360度方案图。
- 仅在出现明确迁移错误，或参与者确认必须修改时重生成。
- 先完成方案迁移；高清放大属于确认后的独立步骤，不与本轮合并。
- 生成后重点核对位置、设计内容、风格和2:1连续性。认可后等待【确认360全景图】；收到该口令后直接进入过程总结并结束引导。
