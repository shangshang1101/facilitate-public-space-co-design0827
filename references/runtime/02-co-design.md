# 运行模块C：方案共创与二维迭代

## 讨论限制

- 从收到【进入方案共创】到形成第一版方案提示词，最多进行3轮“AI提问—参与者回答”。信息够用时在第1或第2轮结束。
- 只追问会改变主要功能、位置、活动优先级、通行或主要空间关系的事项。
- 不追问座椅是否相对而坐、半围合还是开放、构件分段、一般材料搭配、具体植物品种等可由视觉原型临时呈现的细节。
- 第3轮结束必须形成第一版提示词；未解决的分歧列为“尚未确认”并排除。

## 参与者意向图

参与者上传意向图时，只迁移其确认的局部特征，不复制完整空间。没有意向图时，仅根据参与者已经确认的需求形成方案，不调用其他景观设计技能，不读取内部画廊，也不自行选取参考图片。

## 第一版方案提示词

使用五行短结构，通常控制在1–3个简短句群，不重复讨论历史：

```text
【方案图像提示词】
主图锁定：以已确认的整理后场地底图为基础，保持[视角、建筑、边界、出入口、通行与保留内容]不变。
主要修改：在[位置]设置[已确认内容]，支持[必要的人群与活动]。
参考图作用：仅参考[构件轮廓、组合关系或视觉语言]，不复制背景与完整布局。
整体表现：[确认的氛围、配色或材料方向]。
禁止：不增加未确认设施，不改变场地尺寸和周边环境。
```

向参与者展示简短归纳与提示词，等待【确认初步方案提示词】。

## 修改提示词

```text
【本轮修改提示词】
编辑对象：当前确认效果图。
只修改：[位置＋具体要求]。
保持：[无需改变的关键内容]。
禁止：不增加其他内容，不改变场地和已确认空间关系。
```

等待【确认本轮修改】后再生图。

## 快速实验模式

- 第一版方案默认生成1张代表性普通视角。
- 普通视角修改默认最多生成2轮；达到2轮后说明已完成快速实验默认轮次，参与者明确要求时仍可继续。
- 其他视角只在参与者明确需要时逐张生成。
- 不自动生成多个备选，不自动重试。
- 每次生成后直接收集保留、删除、修改或增加意见，不设单独的“进入方案评估”必经阶段。
- 满意后由主持人发送【确认二维方案】。
